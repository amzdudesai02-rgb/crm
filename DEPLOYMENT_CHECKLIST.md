## 🔧 Troubleshooting

### SSL Error (ERR_SSL_VERSION_OR_CIPHER_MISMATCH)
- **Cause**: DNS not pointing to Vercel/Render yet, or SSL not issued
- **Fix**: Wait for DNS propagation (5-30 min), verify domain in Vercel/Render dashboard

### CORS Errors
- **Cause**: Frontend domain not in backend CORS list
- **Fix**: Verify `https://leveragecrm.amzdudes.io` is in `frontend_origins` in `backend/app.py`

### API Calls Failing
- **Cause**: `VITE_API_BASE_URL` not set in Vercel
- **Fix**: Add environment variable in Vercel and redeploy

### Google OAuth Not Working
- **Cause**: Redirect URI not added in Google Cloud Console
- **Fix**: Add `https://api.leveragecrm.amzdudes.io/auth/google` to authorized redirect URIs
